## About The Project
Our project aims to apply the Quantum-Inspired Acromyrmex Evolutionary Algorithm (QIAEA) to identify clusters of companies in business relationships. Our team is going to solve the problem using [Relato Business Graph Database](https://www.kaggle.com/datasets/thedevastator/relato-business-network-graph-373663-domain-conn). This resource provides information about the cooperation of various companies in the online space. Namely, this dataset is a list of sites that have a redirect to the web resources of other organizations.
